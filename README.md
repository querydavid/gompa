# Gompa

A quiet walking piece.

**Play it: https://querydavid.github.io/gompa/**
or download index.html and run it locally.

Best on a laptop or desktop — it's a full 3D scene and phones will struggle. Sound on.

## Controls

| | |
|---|---|
| `W A S D` | walk |
| `← →` or `Q E` | turn on the spot |
| mouse, or click and drag | look |
| `Shift` | slow to a wander |
| `R` | read, at any flame |
| `T` | change the hour — dawn, overcast, dusk, night |
| `C` | draw the constellations |
| `H` | hide or bring back the key list |
| `M` | mute |
| `Esc` | release the mouse |

## Reading

Anything alight is somewhere you can read.

The title screen offers to let you choose a PDF from your own machine.

Walk up to a flame, press **R**, and the PDF opens in a panel.

## Running it yourself

Download `index.html` and open it. That's all — it has no dependencies to fetch and works offline. You can also run it directly from Github Pages.
